# Contributing to Hanmo: Lord of Rivers and Mountains

Thanks for taking an interest in the project.

## Before opening a pull request

1. Start the game through `start-game.bat` or another local static server.
2. Check the affected flow at desktop and mobile widths.
3. Verify that new game content does not introduce downloaded assets or runtime dependencies without a documented reason.
4. Describe gameplay, balance, historical-content, accessibility, and save-compatibility effects in the pull request.

## Repository access

The repository owner and maintainer is [@ZhuangHT-1201](https://github.com/ZhuangHT-1201). Write access is intentionally limited to the maintainer. Automated coding agents and bot accounts are not added as collaborators.

Contributions are accepted through public pull requests so that all changes remain reviewable and attributable.
